# От технической коммуникации к управлению знаниями

Материалы к гостевой лекции для открытого курса для технических писателей.

**Страница с материалами:** https://lananovikova10.github.io/tw-to-km/

Внутри — ресурсы по управлению знаниями, сгруппированные по темам:

- **общее по KM** — прагматичный гайд, модель SECI, KCS, KnowledgeConf;
- **по навыкам** — распаковка знаний и работа с экспертами, термины и шаблоны, находимость и информационная архитектура, культура и процессы, обоснование бизнес-ценности;
- **знания и ИИ** — про второго читателя документации.

Автор лекции — Лана Новикова. Канал [Knowledge & Bacon](https://t.me/the_know_all).
